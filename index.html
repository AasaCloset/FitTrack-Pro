How to setup your Google Sheet Endpoint in 1 minute:

  1. Open a new Google Sheet at sheets.new.
  2. Name column headers in Row 1: Date, Intake (kcal), TDEE (kcal), Deficit (kcal), Protein (g), Water (L), Status.
  3. In Google Sheets menu, click Extensions ➔ Apps Script.
  4. Paste the code snippet below into the editor and click Deploy ➔ New deployment.
  5. Select type Web app, set Execute as: Me, Who has access: Anyone, then copy the Web App URL!
Google Apps Script Code 
function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = JSON.parse(e.postData.contents);
  sheet.appendRow([
    data.date || new Date().toISOString().split('T')[0],
    data.intake || 0,
    data.tdee || 0,
    data.deficit || 0,
    data.protein || 0,
    data.water || 0,
    data.status || 'Target Met'
  ]);
  return ContentService.createTextOutput(JSON.stringify({"result":"success"}))
    .setMimeType(ContentService.MimeType.JSON);
}
